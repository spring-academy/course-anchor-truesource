Open source runs the enterprise. Ninety-seven percent of enterprise applications use open source components, nine in ten Fortune 500 companies run applications built with Spring, and more than 95 percent of enterprises run at least one open source database. Frontier AI models now find vulnerabilities in that software faster than ever, and attackers use the same models to turn disclosures into working exploits in hours, while most enterprise patch cycles still run in weeks.

**TrueSource by Broadcom**, announced at VMware Explore on August 31, 2026, is a portfolio of commercially supported, verifiably built open source software, delivered by the engineers who maintain it. It brings together three offerings under one security and delivery standard:

* **Spring Enterprise**, for Spring and its full dependency tree
* **TrueSource Trusted Artifacts**, for Java, Python, and Node.js libraries, plus hardened container images and Helm charts built with Bitnami technology
* **TrueSource Data Services**, for PostgreSQL, MySQL, Valkey, and RabbitMQ

In this course, you will:

* Understand the problems TrueSource solves, and why AI-generated patches alone can't solve them
* Become familiar with the three TrueSource offerings and the standard they share
* Compare the three sources of a fix for an open source vulnerability: AI-generated patches, aftermarket forks, and the upstream maintainers
* Understand the value proposition of TrueSource for security, development, and platform teams
* Explore example use cases and customer stories
* Map a customer scenario, or an application stack, to the right TrueSource offering
* Explain clean-room builds, SBOMs, signatures, and SLSA provenance, and verify them on a real artifact
* See the benefit hands-on: apply a CVE-only Spring Enterprise patch to an application on an out-of-support Spring Boot line, and verify Bitnami Secure Images before you pull them

The course has two modules:

* **Understanding TrueSource:** see how AI has changed the economics of open source security and where enterprises lose time, then learn what TrueSource is, how each offering works, and where it saves time, risk, and money.
* **TrueSource in Practice:** walk through a real application stack, common scenarios, and customer stories, then patch a Spring Boot application that's out of open source support with a CVE-only Spring Enterprise patch, and verify Bitnami Secure Images before you pull them.

**Who this course is for:** developers and architects who build on Spring, Java, Python, or Node.js; platform engineers who provide build pipelines, base images, and data services; security and vulnerability management teams measured on time to remediate; and technical leaders deciding where TrueSource fits in their software supply chain strategy.

**Prerequisites:** none for TrueSource itself. Familiarity with how applications are built from open source dependencies helps, and the hands-on lab assumes you're comfortable running commands in a terminal.
